# Порядок — CRM для заказов и клиентов

Клиенты, заказы по статусам, оплаты, шаблоны и отчёты. Двусторонняя синхронизация с Яндекс Контактами (CardDAV) с предпросмотром перед применением.

## Онлайн-демо — без установки

**https://fokusnikd-projects.github.io/poryadok-crm/**

Открыл ссылку — и можно пробовать клиентов, заказы, оплаты, шаблоны и отчёты.

- Всё, что вы вводите, хранится **только в вашем браузере**. Сайт — это набор статических файлов на GitHub Pages: сервера, который принимал бы данные, нет, аналитики и сторонних запросов тоже нет.
- Стереть всё: **Настройки → Очистить данные** (или очистить данные сайта в браузере).
- Данные привязаны к этому браузеру на этом устройстве: в другом браузере база будет пустой.
- **Яндекс Контакты в онлайн-демо не работают**: браузер не может подключиться к Яндексу напрямую, для этого нужна программа-посредник. Чтобы проверить синхронизацию, запустите CRM у себя (ниже).

## Как протестировать у себя (рекомендуемый способ)

CRM запускается **на вашем компьютере**. Никакого стороннего сервера нет:

- клиенты и заказы хранятся только в вашем браузере (localStorage для адреса `127.0.0.1:4173`);
- локальный сервер слушает только `127.0.0.1` — из сети и с других устройств он недоступен;
- пароль приложения Яндекса держится только в памяти локального процесса: он не пишется ни в файлы, ни в браузер и пропадает при закрытии окна или через 2 часа;
- единственный внешний адрес, к которому обращается CRM, — `https://carddav.yandex.ru` (другие адреса код запрещает), и только когда вы подключаете Яндекс.

### Запуск

1. Установите [Node.js](https://nodejs.org/ru/download) версии 22 или новее (LTS).
2. Скачайте проект: на GitHub **Code → Download ZIP**, распакуйте в любую папку.
3. Запустите:
   - **Windows** — дважды щёлкните `start-windows.bat`;
   - **macOS / Linux** — в терминале в папке проекта выполните `./start-mac-linux.sh`.

   Первый запуск устанавливает зависимости (около минуты), потом сам откроет браузер на `http://127.0.0.1:4173`.
4. Чтобы остановить CRM, закройте окно запуска (или нажмите Ctrl+C).

Вручную то же самое: `npm ci`, затем `npm run local`.

### Подключение Яндекс Контактов безопасно

1. В [Яндекс ID → Пароли приложений](https://id.yandex.ru/security/app-passwords) создайте пароль типа «Контакты». Основной пароль аккаунта CRM не нужен.
2. В CRM: **Настройки → Яндекс Контакты**, введите почту и этот пароль.
3. **Предпросмотр синхронизации** только читает контакты и показывает, что изменится. Ничего не записывается, пока вы не нажмёте **Применить синхронизацию**.
4. Запись в Яндекс происходит только для:
   - контактов CRM с отметкой «Отправлять в Яндекс» — создаются в Яндексе;
   - связанных контактов, которые вы изменили в CRM, — обновляются в Яндексе.

   CRM никогда не удаляет контакты в Яндексе.

Если хотите проверить синхронизацию, ничего не меняя в Яндексе, ограничьтесь предпросмотром или применяйте её, не ставя отметку «Отправлять в Яндекс» и не редактируя связанные контакты.

### Как всё стереть после теста

1. В CRM: **Настройки → Очистить данные → Очистить всё**. Удаляет всех клиентов, заказы, шаблоны и статусы из браузера, очищает хранилище сайта и отключает Яндекс (пароль стирается из памяти).
2. Закройте окно запуска и удалите папку проекта.
3. В [Яндекс ID → Пароли приложений](https://id.yandex.ru/security/app-passwords) **удалите созданный пароль** — после этого доступа к контактам точно нет ни у какой программы.
4. Если применяли синхронизацию с отметкой «Отправлять в Яндекс», созданные CRM контакты остаются в Яндекс Контактах — их можно удалить там вручную.
5. Если скачивали резервную копию (**Скачать базу JSON**), удалите этот файл: в нём клиенты и контакты.

## Для разработки

```bash
npm ci
npm run dev        # http://127.0.0.1:5173 с горячей перезагрузкой
npm test           # все тесты
```

Онлайн-демо собирается и публикуется автоматически при каждом пуше в `main` ([.github/workflows/pages.yml](.github/workflows/pages.yml)): `VITE_STATIC_DEMO=1 VITE_BASE=/poryadok-crm/ npx vite build`.

Размещение на сервере для нескольких пользователей (логины, SQLite на сервере) описано в [DEPLOY.md](DEPLOY.md). Учтите: в этом режиме данные и пароль Яндекса проходят через сервер того, кто его разместил.
